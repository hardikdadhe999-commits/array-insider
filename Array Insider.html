How Array Elements Are Stored in Memory

Base address = 1000, element size = 4 bytes (conceptual diagram of contiguous memory).

Address of element = Base Address + (Index × Element Size)
Address of A[2] = 1000 + (2 × 4) = 1008

Since every element has the same size and they sit next to each other, the computer can jump straight to any element with one calculation. This is only a simplified picture to understand contiguous memory; real addresses are decided by the system.

What is an Array?

An array is a linear data structure used to store elements of the same data type in contiguous memory locations.

📏

Fixed Size

The size is decided when the array is created and cannot easily change.

🔠

Same Data Type

All elements are of one type, e.g. all int or all float.

🧱

Contiguous Memory

Elements are stored one after another with no gaps.

🔢

Index-Based Access

Each element has an index starting from 0, like A[0], A[1].

⚡

Random Access

Any element can be reached directly without visiting the others.

Characteristics

  • Fixed-size structure
  • Same data type
  • Contiguous memory
  • Index-based access
  • Fast random access

Advantages

  • Fast access using index
  • Easy traversal
  • Simple implementation
  • Memory-efficient for fixed-size data

Disadvantages

  • Fixed size in traditional arrays
  • Insertion can require shifting
  • Deletion can require shifting
  • Searching is slower when unsorted

Applications

  • Storing marks
  • Storing sensor values
  • Tables
  • Matrices
  • Lookup data
  • Implementing other data structures

Time Complexity

OperationBest CaseAverage CaseWorst Case
AccessO(1)O(1)O(1)
SearchO(1)O(n)O(n)
InsertO(1)O(n)O(n)
DeleteO(1)O(n)O(n)
TraverseO(n)O(n)O(n)

Note: For insertion and deletion the exact complexity depends on the position. Inserting or deleting at the end can be O(1) in an appropriate dynamic representation, while shifting elements makes arbitrary-position operations O(n).

Array access is O(1) because the address of an element can be calculated directly using its index.

Array Algorithms

Traversal

START
FOR i = 0 to n-1
    Display A[i]
END FOR
STOP

Linear Search

START
FOR i = 0 to n-1
    IF A[i] == key
        Return i
    END IF
END FOR
Return -1
STOP

Insertion

START
Read position and value
FOR i = n-1 down to position
    A[i+1] = A[i]
END FOR
A[position] = value
n = n + 1
STOP

Deletion

START
Read position
FOR i = position to n-2
    A[i] = A[i+1]
END FOR
n = n - 1
STOP
