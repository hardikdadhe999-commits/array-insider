Contiguous Memory Address Calculation

Base address = 1000, element size = 4 bytes (Calculated dynamically by the backend for each index).

Address of element = Base Address + (Index × Element Size)
Example: Address of A[2] = 1000 + (2 × 4) = 1008

Contiguous layout ensures the CPU can compute any cell memory address in one multiplication and addition (O(1) random access time).

What is an Array?

 
An array is a linear data structure used to store elements of the same data type in contiguous memory locations.

 

  
📏
Fixed Size
Allocated at creation; bounds are strictly enforced.

  
🔠
Same Data Type
All items occupy the same byte footprint (e.g. 4 bytes for int).

  
🧱
Contiguous Memory
Elements reside side-by-side without memory gaps.

  
🔢
0-Based Index
Index equals distance/offset from base memory address.

  
⚡
Direct Random Access
Instant O(1) formula jumps straight to any element.

 

 

  
Characteristics
  • Fixed-size structure
  • Homogeneous data type
  • Contiguous memory allocation
  • Constant-time index access
  • Hardware cache friendly

  
Advantages
  • Instant O(1) random lookup
  • Predictable memory overhead
  • Simple index-based iterations
  • Foundation for Stacks, Queues, Heaps

  
Disadvantages
  • Fixed capacity in traditional arrays
  • Insertion requires right shifting O(n)
  • Deletion requires left shifting O(n)
  • Searching unsorted arrays takes O(n)

  
Applications
  • CPU cache & memory buffers
  • Student mark records & tables
  • Lookup tables & Matrices
  • Implementation of Hash Tables

Core Algorithms & Pseudocode

 

  

   
1. Insertion Algorithm

   
START
IF size >= MAX_CAPACITY THEN
   PRINT "Array Overflow"
   STOP
END IF
FOR i = size-1 DOWN TO pos DO
   A[i + 1] = A[i]  // Shift right
END FOR
A[pos] = newValue
size = size + 1
STOP

  

  

   
2. Deletion Algorithm

   
START
IF size == 0 THEN
   PRINT "Array Underflow"
   STOP
END IF
deletedVal = A[pos]
FOR i = pos TO size-2 DO
   A[i] = A[i + 1]  // Shift left
END FOR
size = size - 1
STOP

  

  

   
3. Linear Search Algorithm

   
START
FOR i = 0 TO size-1 DO
   IF A[i] == target THEN
      RETURN i // Match found
   END IF
END FOR
RETURN -1 // Not found
STOP

  

  

   
4. Traversal Algorithm

   
START
FOR i = 0 TO size-1 DO
   VISIT(A[i])
   PRINT Address = Base + (i * 4)
END FOR
STOP
